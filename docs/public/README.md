# cuet docs

`cuet` lets you model deployment configuration as CUE, compose reusable
primitives, and apply platform policy consistently across modules.

Current backend support in this repository is Terraform/OpenTofu.

## Who this is for

These docs are for teams that want:

- A typed schema for infrastructure modules.
- Reusable resource primitives.
- Consistent provider + backend configuration across apps.
- A small CLI workflow that currently uses Terraform/OpenTofu.
